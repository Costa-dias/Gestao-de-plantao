# Política de Segurança

## Versões suportadas

Apenas a versão mais recente publicada na branch `main` recebe atualizações de segurança.

## Como relatar uma vulnerabilidade

Se você encontrar uma falha de segurança no projeto, **não abra uma Issue pública**.

Em vez disso, envie um relato privado usando a aba **Security** > **Report a vulnerability** no GitHub ou entre em contato diretamente pelo perfil do autor.

Agradecemos por ajudar a manter o projeto seguro!
